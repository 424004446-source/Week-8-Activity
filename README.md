## Description

The Student Grade Report is a simple Dart program that generates a student's grade report using predefined activity and project grades. It demonstrates conditional statements, loops, functions, and basic error handling using `try/catch`.

## Objectives

- Apply conditional statements to determine passing status and academic excellence.
- Use a loop to display report information.
- Create functions that accept parameters and return values.
- Handle invalid numeric input using `try/catch`.
- Practice writing structured Dart programs.

## Program Features

- Displays the student's name.
- Shows activity grade, project grade, and final grade.
- Determines whether the student passed.
- Checks whether the final grade qualifies as excellent.
- Calculates the points needed to reach 100 in the activity.
- Handles invalid numeric input without crashing.
